# Security policy

## Reporting a vulnerability

Email [schilllabs@gmail.com](mailto:schilllabs@gmail.com). Include the repository name, what is affected, and how to reproduce it.

Public repositories also accept a report through GitHub private vulnerability reporting.

Do not open a public GitHub issue for a security report.

## What to expect

Schill Labs will acknowledge the report and follow up with a fix or an explanation. Give us a chance to respond before publishing details.

This policy covers repositories in the Schill-Labs organization and the services those repositories deploy.
